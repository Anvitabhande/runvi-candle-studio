RUNVI CANDLE STUDIO WEBSITE — BEGINNER GUIDE

FILES
- index.html: the website text and sections
- style.css: colours, spacing, fonts and responsive layout
- script.js: mobile menu, current year and WhatsApp setup
- images/: place your own product photographs here if you want to use local files

HOW TO RUN IT
1. Download and extract runvi-candle-website.zip.
2. Install Visual Studio Code from https://code.visualstudio.com/ if it is not installed.
3. In VS Code, choose File > Open Folder and select the extracted runvi-candle-website folder.
4. Open index.html.
5. If you have the Live Server extension installed, right-click index.html and choose Open with Live Server.
   Alternatively, double-click index.html in File Explorer to open it in your browser.

PERSONALIZE THE WEBSITE
1. In index.html, replace the Instagram link https://www.instagram.com/ with your real business profile URL.
2. In script.js, replace 91XXXXXXXXXX with your WhatsApp number including country code, digits only. Example format: 919876543210.
3. Replace the example prices with your current prices.
4. Replace the sample image URLs in index.html with your own product photos. To use a local photo, put it inside the images folder and use a path such as images/sunflower-candle.jpg.
5. Save files with Ctrl+S and refresh the browser.

NOTES
- The sample prices are examples based on previously discussed prices and should be checked before publishing.
- Sample photos load from Unsplash and require an internet connection. Replace them with your own images for accurate product listings.
- This is a front-end starter website. It does not include a shopping cart, database, stock management or online payment checkout.
- Do not publish personal contact details unless you want customers to see them.
